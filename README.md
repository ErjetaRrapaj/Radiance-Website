This website is a clean and simple platform created for a skincare brand as part of a school project. It aims to give users an easy and enjoyable way to learn about the brand, explore its products, and make purchases online.

The homepage introduces the brand’s story and values, helping visitors connect with what the brand stands for. The products page showcases different skincare items with descriptions and prices to help customers make informed choices. Users can add products to their shopping cart and review their selections before checking out. There is also a contact page where visitors can find ways to get in touch with the brand for questions or support.

Built with HTML, CSS, and JavaScript, the website features basic online shopping functionality and a clean, user-friendly design. This project was created to practice building a website that looks good and is simple to use.
